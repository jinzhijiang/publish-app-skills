# 阿里应用分发 · 浏览器发布合同

> 仅记录可公开复核的控制台路由和界面约束。认证会话、Cookie、令牌、测试凭据、动态上传地址及请求头不记录、不导出，也不能用于本地接口调用。
>
> 这条约束**不禁止**在已登录的控制台标签页**内部**调用平台自己的接口读状态——凭据在这种做法里
> 始终留在浏览器上下文，没有被读取或导出。只读状态查询见
> 本 skill 的 `SKILL.md` § 0。

## 实测入口（2026-09-01）

| 用途 | 路由 / 入口 | 实时页面信号 |
| --- | --- | --- |
| 控制台首页 | `https://open.9game.cn/` | 已登录后显示开发者主体名称与“软件发布”入口 |
| **应用列表** | `https://aliapp-open.9game.cn/app/mng/index` | 列出目标应用、包名、版本与状态（2026-09-02 补记） |
| 软件发布表单 | `https://aliapp-open.9game.cn/addapp` | 标题为“安卓应用管理 > 创建软件” |

> 会话过期时 `aliapp-open.9game.cn/*` 会重定向到 `https://open.9game.cn/login`，
> 登录方式为淘宝账号 / 九游 / 豌豆荚三选一，由账号持有人手动完成。
>
> 页面是 SPA，`get_page_text` 在渲染完成前会返回只有页脚与公告的空壳，导航后需等待再读。

每次先从首页的“软件发布”链接进入；不要依据历史应用 ID、标签页或网络请求拼接更新地址。若页面没有明确显示既有应用的更新流程，暂停并请账号持有人确认，避免创建重复应用。

## 表单合同

- APK 必须由可见的“上传APK”控件上传；上传后以页面解析结果为准。
- 必填资料包括：名称、分类、一句话简介、应用描述、新版特征、隐私政策、收费描述、广告状态、支持语言、备案主体资料、图标、至少 4 张截图及证明材料。
- 页面展示的“无风险违规 SDK 自查”是独立合规声明，不能由上传或最终提交授权替代。
- “提交应用”会进入审核，不能当作保存草稿；最终点击前必须重新核对平台解析版本、MD5、更新说明与声明状态。

## 状态与安全边界

- 审核期间页面提示不能编辑应用信息；成功后再以应用列表的审核状态复核。
- 仅通过 Chrome 已登录会话完成 UI 操作；不要读取或持久化浏览器登录标识、Cookie、令牌或请求头。
- 不采集临时上传 URL 或 XHR/API 路径：它们既非稳定发布接口，也可能关联当前认证会话。
